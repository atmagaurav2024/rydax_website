Features

Everything a project needs, in one app

Project planning

Break a project into phases and tasks, set dates and dependencies, and see the whole schedule at a glance.

Progress tracking

Record daily site progress and compare planned against actual, so delays show up early.

Budget control

Track estimates, spending and variations against the budget for each project.

Drawings and files

Keep drawings, contracts and reports with their project, always at the latest revision.

Tasks and people

Assign work to engineers, supervisors and subcontractors, and see who owns what.

How it works

From first plan to handover

  1. Set up the project

    Add the project, its phases, budget and the team working on it.

  2. Run the site

    Update tasks and progress as work happens. Everyone sees the same current picture.

  3. Review and hand over

    Check progress and cost against the plan, then close out with the records in order.
